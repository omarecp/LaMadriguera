# La Madriguera

Static landing page for a friend's coffee shop.

## Starter Task

Build a polished, responsive one-page landing page that gives the shop an immediate web presence.

Included sections:

- Hero with brand message and calls to action
- Featured drinks and bakery items
- About section
- Visit details with hours, address, and contact links

## How to View

Open `index.html` in a browser. No build step is required.
